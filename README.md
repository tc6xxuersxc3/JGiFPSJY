# 项目简介

## 核心功能
- 基于 YOLOv8 小麦病害检测系统，包含全部源码、完整标注数据集和训练好的模型
- 支持 3 类小麦病害检测：Bacteria_Leaf_Blight、Brown_Spot、Leaf_smut
- 提供 6000 张标注数据集用于训练和测试
- 支持多种输入源检测：单张图片、图片文件夹、视频文件、本地摄像头
- 界面功能包括：实时显示目标位置、目标总数、置信度信息
- 支持自定义检测参数：置信度阈值、IOU阈值
- 支持选择不同检测模型
- 支持检测结果保存和批量检测查看

## 适用场景
- 农业科研机构的小麦病害研究
- 农业生产中的病害早期检测
- 农业技术推广和培训
- 农业智能监测系统开发参考

## 技术特点
- 基于 Python 3.9 开发，依赖环境包括 opencv-python、PyQt5、ultralytics、torch1.9
- 使用 PyCharm+Anaconda 或 VSCode+Anaconda 作为开发环境
- 采用 PyQt5 构建图形用户界面
- 模型训练基于 YOLOv8 框架，支持深度学习目标检测
- 提供完整的程序文件、UI界面源文件和数据集资源
